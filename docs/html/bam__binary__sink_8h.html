Detailed Description

API of the binary sink used in parsing the AC-4 TOC.

The sink creates a list of presentations present in its frame buffer and allows to set "presentation_level" field for them.
Before the presentations can be accessed they need to be parsed by the BAM-generated AC-4 TOC parser. Create an instance of the sink with bam_binary_sink_create with the same buffer as given to the source and pass it to F_raw_ac4_frame_toc_only_parse.
