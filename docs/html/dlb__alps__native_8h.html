alps_ret alps_process_isobmff_segment ( alps_ctx *  ctx,
unsigned char *  buffer,
size_t  size 
)

Parses list of presentations out of given ISOBMFF segment and sets the active presentation in all the AC-4 samples it contains.

Parameters
[in]ctxpointer to the library context
[in]buffermemory buffer holding the ISOBMFF segment
[in]sizesize of the buffer in bytes
Returns
  • ALPS_RET_E_INVALID_ARG if ctx or buffer is 0
  • ALPS_RET_E_PARSE if the segment or contained AC-4 samples could not be successfully parsed
  • ALPS_RET_E_NO_AC4_TRACK if no AC_4 track could be found in the segment
  • ALPS_RET_OK if the operation succeeds
